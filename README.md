## 🔐 Ce que la cybersécurité apporte à mes intégrations IA

Un assistant branché sur les données d'une entreprise est une surface d'attaque. Mon travail en
détection m'a appris à la traiter comme telle :

- secrets hors du code et hors des dépôts, détection automatisée avant chaque publication ;
- entrées validées aux frontières, injection de prompt prise en compte dès la conception ;
- données personnelles réduites au strict nécessaire ;
- relecture de sécurité confiée à un agent distinct de celui qui écrit le code.

Mes projets de détection — [Splunk](https://github.com/sofiane779/DNS-Exfiltration-DGA-Detection),
[Sysmon](https://github.com/sofiane779/Windows-Endpoint-Monitoring-Threat-Detection),
[threat intel en Python](https://github.com/sofiane779/Threat-Intel-Dashboard) — sont visibles
ci-dessous.
